# Configuration serveur par défaut

Cette version est préconfigurée pour le serveur Yam-Trans déployé sur Hostinger.

- API de synchronisation : `https://sync.print-station.tech`
- Page publique de suivi : `https://sync.print-station.tech/suivi`
- Synchronisation : activée par défaut
- Synchronisation automatique : activée par défaut
- Clé API : valeur par défaut actuelle du serveur (`CHANGE-ME-WITH-A-LONG-RANDOM-KEY`)

Les réglages restent modifiables depuis le compte Super utilisateur.

> Sécurité : lorsque la phase de test sera terminée, remplacez la clé API par une clé aléatoire longue sur le serveur et dans les applications.
