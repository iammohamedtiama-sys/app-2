# Yam-Trans Android v3.5

## Formulaires opérationnels
- Après création réussie d’une agence, d’un utilisateur, d’une dépense, d’un élément d’exploitation ou d’une société, le formulaire est réinitialisé.
- Le parcours revient à l’étape 1.
- Une notification confirme l’enregistrement et indique que le formulaire est prêt pour une nouvelle saisie.
- Les formulaires de paramètres restent remplis avec les valeurs enregistrées : ils ne sont pas vidés car ce sont des formulaires de configuration, pas de création répétitive.

## Super Super Admin
- Bouton **Modifier** sur chaque société.
- Modification du nom, téléphone, couleurs, titre/sous-titre de suivi, email support et site web.
- Remplacement facultatif du logo par upload.
- Le code société reste non modifiable afin de préserver les liens de suivi et l’isolation des données.
- Annulation de l’édition possible.
